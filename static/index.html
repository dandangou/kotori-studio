LOCAL FIRST

模型与运行环境

模型首次下载后可离线使用。处理任务依次运行，避免同时占用内存。

存储管理

仅清理可重新生成的音频 / 播放代理，保留源视频、字幕和导出文件。

02 / TRANSCRIBE

日语语音识别

识别会替换此范围内的字幕。日语人名、笑声、重叠说话和游戏音效需要复核；可在项目资料里设置术语提示。

03 / TRANSLATE

中文初译

仅向你指定的服务发送所选范围的字幕文本及术语。密钥只保留在本次运行内存中。

保留日文原文，初译不会自动标记为已校对。

FINISH & EXPORT

导出作品

字幕随保留片段自动换算为成片时间。视频精确裁剪需要重新编码。

PROJECT NOTES

项目资料与术语

每行一项，用「日文 = 中文」指定译法。术语表用于识别提示和翻译上下文，原片链接保存在本地项目中。

IMPORT SUBTITLES

导入 SRT 字幕

日文字幕会替换现有字幕；中文字幕会匹配已有时间轴填入译文，无法匹配的条目会新增。可先导出备份。

TIMING OFFSET

整体偏移字幕时间

正数延后，负数提前，最多保留 3 位小数。例如 -0.250 表示提前 250 毫秒。

当前选区按字幕与选区是否重叠选取。保持每条字幕时长、文字和校对状态；任何一条移出视频范围时，整次操作都不会应用。

MY CLIPS

我的切片

一场直播可保存多个切片，每个切片可由多段组成。字幕和角色配色共用，校对一次即可复用。编辑拼接后，请在这里更新对应切片；已导出的文件需重新导出才会更新。

STORY EDIT

拼接成片

每行是一段保留的原片。按清单顺序连播、导出；中间未列出的部分会跳过。字幕继续在原片上翻译，导出时自动重排时间。

角色与字幕配色

修改一次会应用到这个项目中所有对应字幕。每条字幕勾选一人显示单色，勾选多人显示字内分色；齐声的颜色顺序按勾选顺序。

颜色保存在项目中。ASS 与烧录视频保留配色；SRT 为纯文字。未选说话人的字幕保持白色。
